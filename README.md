# Сайт-портфолио Rabia

Обычный сайт из файлов HTML, CSS и JavaScript. Ничего собирать и устанавливать не нужно. Открыть его на своём компьютере можно двойным кликом по `index.html`.

## Что где лежит

| Что | Где |
|---|---|
| Все тексты сайта (русский и английский), цены, сроки, часы работы | `content/texts.js` |
| Проекты (добавлять новые здесь) | `content/projects.js` |
| Ссылки, ваше фото, материалы кейса Kinni, переключатели | `content/settings.js` |
| Картинки проектов | `images/projects/` |
| Картинки кейса Kinni | `images/kinni/` |
| Вёрстка и внешний вид | `index.html`, `css/style.css` |
| Страница одного кейса | `case.html` |
| Политика обработки персональных данных | `privacy.html` |
| Шрифты | `fonts/` |
| Иконка вкладки и картинка для ссылок в мессенджерах | `favicon.svg`, `og.png` |

В файлах из папки `content` меняйте только то, что внутри кавычек. Слова слева от двоеточия (ключи) не трогайте.

## Где разместить сайт

Сайт статический, поэтому подойдёт любой хостинг, который умеет отдавать файлы. Два варианта.

**GitHub Pages — бесплатно, проще всего.** Запрета на использование зарубежного хостинга для владельца сайта в российском законе нет: требование быть в реестре Роскомнадзора обращено к самим хостинг-провайдерам, а не к их клиентам. GitHub в список провайдеров, чьи сайты ограничивал Роскомнадзор, не входит. Минус один: если доступ к GitHub из России когда-нибудь ограничат, сайт перестанет открываться у заказчиков.

**Yandex Cloud Object Storage — бесплатно в рамках стартового уровня, российский хостинг.** Снимает вопрос с доступностью. Настройка сложнее: нужно создать бакет, включить режим «хостинг статического сайта» и загрузить файлы, обязательно указывая тип содержимого для каждого (иначе браузер получит CSS как неизвестный файл и сайт откроется без оформления). Для работы по HTTPS понадобится свой домен, это около 800 ₽ в год.

Начните с GitHub Pages: его можно настроить за десять минут и в любой момент переехать, просто загрузив те же файлы в другое место.

## Как выложить на GitHub Pages

1. Зарегистрируйтесь на github.com и нажмите **New repository**.
2. Название репозитория: если назовёте его `ваш-логин.github.io`, сайт будет по адресу `https://ваш-логин.github.io/`. Любое другое название даст адрес `https://ваш-логин.github.io/название/`. Поставьте **Public** и создайте репозиторий.
3. На странице репозитория нажмите **uploading an existing file**. Перетащите внутрь **содержимое** папки с сайтом (файл `index.html` должен лежать в корне, а не внутри вложенной папки). Нажмите **Commit changes**.
4. Откройте **Settings**, затем **Pages**. В пункте **Build and deployment** выберите **Deploy from a branch**, ветку **main** и папку **/ (root)**, нажмите **Save**.
5. Через 1–2 минуты на этой же странице появится адрес сайта.
6. Замените адрес в трёх местах `index.html` (см. ниже) и загрузите файл заново: на странице репозитория нажмите на `index.html`, затем на значок карандаша, вставьте исправленный текст и нажмите **Commit changes**.

Чтобы обновить сайт позже, заходите в репозиторий, нажимайте **Add file, Upload files** и загружайте изменённые файлы поверх старых.

## Что нужно заменить перед запуском

- [ ] **Адрес сайта.** В `index.html` найдите `ВАШ-ЛОГИН.github.io/НАЗВАНИЕ-РЕПОЗИТОРИЯ` (3 строки: `canonical`, `og:url`, `og:image`) и впишите настоящий адрес.
- [ ] **Ваше фото.** Положите файл в папку `images` (например, `rabia.jpg`) и впишите `'images/rabia.jpg'` в `portrait` в `content/settings.js`.
- [ ] **Картинки проектов.** Положите их в `images/projects/` и впишите пути в `images` каждого проекта в `content/projects.js`.
- [ ] **Ссылки на Behance** по каждому проекту: поле `behance` в `content/projects.js`. Пока пусто, кнопки у проекта нет.
- [ ] **Кейс Kinni:** 5 картинок (`images` в `settings.js`), ссылка на видео (`videoUrl`) и, если нужно, на макеты (`caseUrl`).
- [ ] **Когда всё заполните:** в `content/settings.js` поставьте `showPlaceholders: false`. Серые подсказки «Здесь будет…» исчезнут.
- [ ] **Картинка для ссылок в мессенджерах** `og.png` сделана автоматически (название и слоган). При желании замените своей, размер 1200×630.
- [ ] **Цены в долларах** ($1,500 / $3,000 / $4,500) я поставила пропорционально рублёвым. Проверьте их и поправьте в `services.min.price`, `services.base.price`, `services.max.price` в английском блоке `en`.
- [ ] **Английские тексты** прочитайте глазами. Их перевела не носительница языка.
- [ ] **Блок «Следующий проект»** в конце списка: уберите, поставив `comingSoonCard: false`.

## Как добавить новый проект (раз в месяц)

1. Подготовьте картинки: ширина 1600 px, формат JPG или WebP, не больше 300 КБ на файл. Положите их в папку проекта, например `images/projects/nomad/`, называйте латиницей без пробелов: `cover.jpg`, `01.jpg`, `02.jpg`.
2. Откройте `content/projects.js`. Скопируйте любой готовый блок целиком, от `{` до `},` включительно.
3. Вставьте копию **сразу после строки `window.PROJECTS = [`**. Тогда новый проект окажется первым на сайте.
4. Заполните `id`, `cover`, тексты в `ru` и `en`, а затем `story` — содержимое страницы кейса. Если цифр результата нет, оставьте `stats: []`.
5. Загрузите файлы на хостинг. Вёрстку трогать не нужно: и карточка, и страница кейса появятся сами.

## Страницы кейсов

Каждый проект открывается на вашем сайте, а не на стороннем сервисе. Карточка на главной и кнопка «Смотреть кейс» ведут на `case.html?id=` и дальше имя проекта, например `case.html?id=nomad`. Внизу кейса есть кнопка «Обсудить проект» и ссылки «Все проекты» и «На главную».

Файл `case.html` один на все проекты, добавлять новый не нужно. Содержимое берётся из `story` в `content/projects.js`:

- `lead` — вводная фраза под заголовком, отдельно для `ru` и `en`;
- `blocks` — блоки по порядку, сверху вниз. Их два вида:

```
{ t: 'text', ru: { title: 'Айдентика', text: '…' },
             en: { title: 'Identity',  text: '…' } }

{ t: 'img',  src: 'images/projects/nomad/01.jpg',
             ru: { alt: 'Персонажи бренда', caption: '' },
             en: { alt: 'Brand characters',  caption: '' } }
```

`alt` — короткое описание картинки для незрячих, заполняйте обязательно. `caption` — подпись под картинкой, можно оставить пустой. Пока `src` пустой, на месте картинки стоит серая подсказка.

Тексты кейсов я перенесла с вашего dprofile. **Картинки нужно выгрузить и положить в папки самостоятельно**: скачать их с dprofile автоматически не получилось. На dprofile в кейсах 11 изображений у Vivante, 7 у Florista и 12 у НОМАДа. Лучше брать оригиналы из ваших исходников, а не пересохранённые копии с сайта.

## Как поменять цены, сроки и часы работы

Всё в `content/texts.js`. Для русской версии ищите блок `ru`, для английской `en`:
- цены и сроки пакетов: `services.min`, `services.base`, `services.max`. В каждом поля `price` (цена), `terms` (срок и раунды правок), `fit` (кому подходит) и `items` (что входит);
- какой пакет помечен словом «Рекомендую»: подпись в `services.rec`, а сама плашка стоит в `index.html` в средней карточке (`<p class="rec" …>`);
- разница в цене под карточками: `services.diff`. Сейчас там 105 000 ₽ и 110 000 ₽, пересчитайте, если измените цены;
- сроки по этапам: `process.stages` (название и дни) и `process.total` (итог);
- оплата, правки, что нужно от клиента и что он получает: блок `terms`;
- часы ответов: `process.note`.

## Шрифты

- **PT Serif Regular** для заголовков. Шрифт ParaType, лицензия SIL Open Font License, бесплатен в том числе для коммерческих проектов (текст лицензии в `fonts/LICENSE-PT-Serif.txt`).
- **Geist** и **Geist Mono** для основного текста, цен и мелких подписей, лицензия SIL Open Font License (текст в `fonts/LICENSE-Geist.txt`).

Чтобы поменять шрифт заголовков, положите файл в `fonts/`, замените блок `@font-face` в начале `css/style.css` и строку `--display` чуть ниже.

Все шрифты лежат на сайте, ничего внешнего не загружается, поэтому сайт быстро открывается и не зависит от сторонних сервисов.

## Что проверено

- Переключатель RU/EN: язык выбирается по настройкам браузера, выбор запоминается.
- Телефон, планшет, компьютер: нет горизонтальной прокрутки на ширинах от 320 до 1920 px.
- Контраст всех текстов не ниже 4,5:1.
- Весь сайт проходится клавишей Tab, у каждого элемента виден контур фокуса, меню на телефоне закрывается клавишей Esc.
- При включённой в системе настройке «уменьшить движение» анимации отключаются, а пример на первом экране не запускается сам.
- Открывается двойным кликом по `index.html` и работает на GitHub Pages.

## Что не сделано

- Нет ваших картинок и фото: сайт ждёт их на местах, отмеченных серыми подсказками.
- Нейросети на сайте не упоминаются. Когда появится кейс с ними, добавьте проект в `projects.js` и расскажите, как вы их использовали.

## Картинки кейса и плавные переходы

- Картинки Vivante лежат в `images/projects/vivante/01.webp … 10.webp`, обложка карточки на главной — `09.webp`; НОМАД — `images/projects/nomad/01…12.webp`, обложка `02.webp`. Чтобы сменить обложку, поменяйте путь в поле `cover` в `content/projects.js`. `tone: 'dark'` / `'light'` в `story` — сплошной чёрный/белый фон без просветов; `gap: true` у картинки — небольшой просвет после неё.
- Блок «О проекте» (заказчик, задача, срок, решение, цифры) собирается из полей `client`, `caseTask`, `timeline`, `solution`, `caseStats` у проекта. Если `client` пуст, на странице кейса остаётся обычный короткий блок «Задача / Что я сделала».
- Переходы между страницами (главная, кейс, политика) делает `js/transitions.js`: страница мягко гаснет, следующая проявляется. Если в системе включено «уменьшить движение», переходы обычные. Кнопка «← Все проекты» на кейсе возвращает ровно на то место главной, откуда вы пришли.
